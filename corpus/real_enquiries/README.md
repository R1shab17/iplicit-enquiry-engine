# corpus/real_enquiries/

Raw, unmodified `dbo.enquiry` / `dbo.enquiry_layout` rows (or full export
envelopes) pulled directly from a real iplicit tenant — not distilled,
not summarised, not regenerated. This is the ground truth the rest of the
repo's knowledge was originally distilled from (see
`docs/ARCHITECTURE.md`'s "How the knowledge was originally obtained").

**Currently empty.** The original 640-definition exploration that produced
`docs/IPLICIT_ENQUIRY_MASTER_SKILL.md` was done in an earlier session via a
live browser hook and was not saved back into this repo as raw data — only
the distilled patterns were kept. Closing that gap is `docs/ROADMAP.md`
item 1.

## What belongs here

- The raw JSON result of `SELECT * FROM dbo.enquiry` / `dbo.enquiry_layout`
  (or a filtered subset), pulled via the preview-runner hook described in
  `docs/IPLICIT_ENQUIRY_MASTER_SKILL.md` §9.
- A real enquiry's `⋮ > Export to clipboard` output, saved verbatim.

## What doesn't

- Anything hand-written or generated by `src/enqgen.py` — that belongs in
  `generated/` or `experiments/`.
- A "cleaned up" or reformatted version of a real export — keep these
  byte-for-byte as pulled, so `src/enquiry_parser.py` can decode them the
  same way it would decode a fresh pull, and so a diff against a generated
  enquiry is meaningful.

## Naming

`<tenant-or-context>_<enquiry-name-or-id>.json` (or `.sql` for a raw query
result) — enough to trace back to where and when it was pulled.
